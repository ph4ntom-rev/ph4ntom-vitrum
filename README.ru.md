## 📌 Общее описание

Концепция **ph4ntom Vitrum** (*in vitro* — *«за герметичным стеклом»*) предназначена для автоматизации рутинных задач первичного разбора артефактов и статического реверс-инжиниринга в защищённой среде:

- **Строго статический контур (*In-Vitro*):** исследование бинарных файлов, пакетов, документов и архивов выполняется исключительно статическими методами без запуска исследуемого кода в системе аналитика.
- **Интеграция с IDA Pro 9.x:** автоматизированное управление изолированными фоновыми сессиями **IDA Pro 9.0–9.5** на базе открытого моста [ph4ntom-ida-bridge](https://github.com/ph4ntom-rev/ph4ntom-ida-bridge) без вмешательства в открытые вручную рабочие окна аналитика.
- **Гибкое подключение ИИ-моделей:** поддержка как облачных, так и полностью локальных (*on-premise*) моделей для работы в контурах с повышенными требованиями к конфиденциальности данных.
- **Структурированная отчётность и разграничение прав:** формирование стандартизированных аналитических сводок с контролем достоверности выводов и ролевой моделью доступа операторов.

## 🧩 Открытые компоненты экосистемы

Ядро **ph4ntom Vitrum** закрыто, однако базовый интерфейс автоматизации **IDA Pro 9.x** доступен отдельно в открытом исходном коде:

- **[ph4ntom-ida-bridge](https://github.com/ph4ntom-rev/ph4ntom-ida-bridge)** — MCP и REST-интерфейс автоматизации для IDA Pro 9.0–9.5.
